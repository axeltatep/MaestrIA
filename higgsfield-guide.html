Claude Code + Higgsfield
Setup Guide

Automatiza tu producción de contenido IA · De idea a video sin cambiar de ventana

Normalmente crear contenido IA requiere alternar entre múltiples herramientas: escribir prompts, generar imágenes, generar videos, editar outputs, gestionar archivos. Claude Code cambia esto. Con un solo archivo — CLAUDE.md — defines cómo trabajas, y Claude opera Higgsfield automáticamente por ti.

Sin Claude Code
  • Copy-paste entre pestañas
  • Repetir configuraciones cada vez
  • Inconsistencia entre sesiones
  • Workflow manual y lento
Con Claude Code
  • Genera prompts automáticamente
  • Controla Higgsfield directamente
  • Organiza assets en carpetas
  • Sigue tus reglas de producción

02
Setup en 5 pasos
1

Instalar Claude Code

Abre la terminal y ejecuta:

npm install -g @anthropic-ai/claude-code

Luego inicia Claude:

claude

Claude ya está corriendo.

2

Crear tu CLAUDE.md

Este archivo le enseña a Claude cómo trabajas. Claude lo lee automáticamente al inicio de cada sesión. Crea el archivo en la raíz de tu proyecto:

CLAUDE.md
# Mi Workflow ## Herramientas Imágenes: Higgsfield NanoBanana Pro Videos: Higgsfield Cinema Studio ## Configuración base Aspect ratio: 16:9 Imágenes: 8 por prompt Resolución: 2K unlimited ON ## Reglas - Mostrar prompts antes de generar - Esperar confirmación del usuario - Guardar en /output

Puedes personalizar esto como quieras.

3

Instalar Playwright MCP (IMPORTANTE)

Este paso habilita el control del navegador. Sin esto, Claude no puede abrir Higgsfield.

claude mcp add playwright npx '@playwright/mcp@latest'

Reinicia Claude:

exit claude

Verifica:

/mcp

Deberías ver:

playwright

Ahora Claude puede controlar un navegador.

4

Probar el control del navegador

Prueba la navegación:

Use playwright to open higgsfield.ai

Claude debería abrir el navegador y navegar al sitio. Inicia sesión manualmente. Luego escribe:

Continue
5

Probar control de Higgsfield

Prueba que Claude puede operar configuraciones:

Use playwright to open NanoBanana Pro. Set: 16:9 aspect ratio 2K unlimited ON extra free gens OFF Do not generate.

Si Claude puede cambiar los settings, tu setup funciona.

03
Cómo funciona Claude con Higgsfield
→

Después del setup, Claude puede:

Abrir Higgsfield · Cambiar configuraciones · Ingresar prompts · Generar imágenes · Generar videos · Organizar outputs en carpetas.

Todo controlado mediante instrucciones o tu CLAUDE.md. Ejemplo:

Generate 5 cinematic product images using NanoBanana Pro. Aspect ratio 16:9. 8 images per prompt.

Claude abrirá Higgsfield → establecerá el modelo → ingresará los prompts → generará las imágenes.

07
Tips
!

Si Claude hace algo incorrecto — díselo

Claude se adapta rápido. Ejemplo:

Do not generate yet. Show prompts first.

También puedes agregar reglas permanentes a tu CLAUDE.md.

08
Problemas comunes
Claude no puede abrir Higgsfield
Verifica el MCP:
/mcp
Si no aparece playwright, reinstala:
claude mcp add playwright npx '@playwright/mcp@latest'
Luego reinicia Claude.
Claude abre un navegador nuevo
Esto es normal. Playwright usa un navegador controlado — no tu Chrome personal. Inicia sesión en Higgsfield desde ese navegador controlado.
Claude genera antes de tiempo
Dile:
Wait for confirmation.
O agrega la regla a tu CLAUDE.md para que aplique siempre.
